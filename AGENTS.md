## Priority Order

Security > Correctness > Maintainability > Scalability > Performance > Development Speed

## Mandatory Requirements

Before writing any code:

1. Analyze existing architecture.
2. Analyze current codebase patterns.
3. Analyze security implications.
4. Analyze scalability implications.
5. Analyze performance implications.
6. Analyze database implications.
7. Analyze maintainability implications.

Do not immediately generate code.

Think first.

## Modern Framework Rule

Always use:

* Latest stable Next.js patterns
* Latest stable React patterns
* Latest stable TypeScript patterns

Avoid deprecated APIs.

Avoid outdated tutorials.

Prefer official documentation over memory when uncertainty exists.

## Security Rule

Assume all:

* User input
* API requests
* Uploaded files
* Webhook payloads
* Query parameters

are untrusted and potentially malicious.

Apply security review to every change.

## Quality Rule

All code must be:

* Production-ready
* Secure
* Type-safe
* Maintainable
* Testable
* Scalable

Never introduce technical debt intentionally.

## Completion Checklist

Before completing any task verify:

✓ Authentication

✓ Authorization

✓ Validation

✓ Error Handling

✓ Type Safety

✓ Security

✓ Performance

✓ Maintainability

✓ Production Readiness

If any item fails, explain the issue before proceeding.
